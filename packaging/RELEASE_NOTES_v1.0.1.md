# STEP to ACIS Converter v1.0.1

- First MIT-licensed public release with neutral project naming and privacy-clean public source.
- Rebuilt Windows x64 portable package; verify the release-specific `.sha256` sidecar before use.
- Requires a separately licensed local Ansys SpaceClaim 2022 R2 installation; no vendor software or documentation is redistributed.
- The package is unsigned, so Windows SmartScreen may display a warning.
- Compatibility remains limited to the documented, verified ACIS V22 boundary.
